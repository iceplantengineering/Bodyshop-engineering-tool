# Bodyshop Engineering Tool

3Dモデルと関連データ（溶接点、ロケーター、ピンなど）を視覚化し、編集するためのWebアプリケーションです。

## 主な機能

### 基本機能
-   STL/OBJ形式の3Dモデルの読み込みと表示
-   CSV形式でのWeld Point, Locator, Pinデータの読み込み、表示、編集
-   オブジェクトの選択、移動、回転
-   プロパティ編集パネル
-   工程（Process）によるデータフィルタリング
-   データの追加・削除
-   フィルタリングされたデータのエクスポート

### 高度な編集機能
-   **アンドウ/リドゥ**: Ctrl+Z / Ctrl+Shift+Z で最大50ステップまで履歴を戻せる
-   **オブジェクト複製**: Ctrl+D で選択オブジェクトを複製
-   **測定ツール**: 3D空間での距離・角度測定
-   **整列ツール**: グリッドにスナップ、X/Y/Z軸への整列
-   **回転中心制御**: 選択オブジェクトを回転中心に設定、視覚的インジケーター表示

### カメラ制御
-   **プリセットビュー**: 上/下/左/右/前/後/X/Y/Z/等角ビュー
-   **回転中心設定**: 任意のオブジェクトを回転中心に設定可能
-   **クリッピング調整**: Near/Farプレーンの調整
-   **選択時フォーカス**: オブジェクト選択時に自動的にフォーカス（ON/OFF可能）

### UI機能
-   **キーボードショートカットヘルプ**: `?` キーでヘルプダイアログ表示
-   **スライス画像ギャラリー**: 生成された断面画像の表示・ダウンロード
-   **エレメント管理パネル**: 各要素の表示/非表示切り替え

### 断面画像生成機能 (PythonバックエンドAPI連携)

本プロジェクトには、指定されたOBJモデルとLOCATOR情報（位置、回転）に基づき、LOCATORの位置でモデルの断面（または断面に近いビュー）の画像を生成する機能が含まれています。

## 断面画像生成API

### バックエンド (Python API)

-   **フレームワーク**: Flask
-   **主要ライブラリ**:
    -   `PyVista` (及び `VTK`): 3Dメッシュの読み込み、スライス処理、画像生成
    -   `Flask-CORS`: フロントエンドからのクロスオリジンリクエストを許可
    -   `Pillow`: 画像処理
    -   `numpy`: 数値計算
-   **実行ファイル**:
    -   `app.py`: Flask APIサーバーのメインファイル。`/slice` エンドポイントを提供。
    -   `slice_obj.py`: PyVistaを使った断面画像生成ロジックを実装。
-   **APIエンドポイント**:
    -   `POST /slice`
        -   リクエストボディ (JSON):
            ```json
            {
              "obj_file_path": "data/your_model.obj",
              "locators": [
                {
                  "id": "LOC001",
                  "x": 10.0, "y": 20.0, "z": 30.0,
                  "rx": 0, "ry": 0, "rz": 0
                }
              ]
            }
            ```
        -   レスポンス (JSON):
            -   成功時: 処理結果のメッセージ、生成された画像のパスなど
            -   失敗時: エラーメッセージ

## セットアップと実行

### 1. Python環境のセットアップ

-   Python 3.10 の使用を推奨します。
-   プロジェクトルートにPython 3.10の仮想環境を作成します。

    ```bash
    # Windows (PowerShell)
    py -3.10 -m venv .venv310
    .\.venv310\Scripts\activate

    # macOS/Linux
    python3.10 -m venv .venv310
    source .venv310/bin/activate
    ```
-   必要なPythonライブラリをインストールします。

    ```bash
    pip install Flask flask-cors pyvista Pillow numpy open3d
    ```

### 2. APIサーバーの起動

-   仮想環境がアクティベートされたターミナルで、プロジェクトルートから以下を実行します。

    ```bash
    python app.py
    ```
-   APIサーバーが `http://localhost:5000` で起動します。

### 3. フロントエンド開発サーバーの起動

-   別のターミナルを開き、プロジェクトルートでフロントエンドの開発サーバーを起動します。

    ```bash
    npm install  # 初回のみ
    npm run dev
    ```
-   開発サーバーが `http://localhost:5173` (または別のポート) で起動します。

### 4. 機能の利用

-   ブラウザでフロントエンドのURL (例: `http://localhost:5173`) を開きます。
-   OBJモデルとLOCATORデータをロードします。
-   右側のコントロールパネルでLOCATORを選択し、「断面画像生成」ボタンをクリックすると、APIが呼び出され、断面画像が `data/generated_slices/` ディレクトリに保存されます。
-   生成された画像は「ギャラリー」ボタンから確認・ダウンロードできます。

## 使用方法

### 基本操作

1. **データの読み込み**
   - 左パネルの「Load Model」でSTL/OBJファイルを読み込み
   - 「Load Weld Points」「Load Locators」「Load Pins」でCSVファイルを読み込み

2. **オブジェクトの編集**
   - 3Dビュー上でオブジェクトをクリックして選択
   - プロパティパネル（左下）で座標・回転・ID等を編集
   - TransformControls（ギズモ）で直接ドラッグして移動・回転

3. **測定**
   - 「測定ツール」パネル（上中央）で「距離」または「角度」を選択
   - 距離: 2点をクリック
   - 角度: 3点をクリック（最初の点が頂点）

4. **回転中心の制御**
   - 「選択オブジェクトを中心に」で選択中のオブジェクトを回転中心に設定
   - 「原点にリセット」または何もない場所をダブルクリックで原点に戻す
   - 「中心を表示」で回転中心のインジケーターを表示/非表示

## CSVデータ形式

### Weld Point
```csv
id,process,x,y,z,gun,notes
WP001,PROCESS_A,100,200,50,Gun1,Example note
```

### Locator / Pin
```csv
id,process,x,y,z,rx,ry,rz,notes
LOC001,PROCESS_A,100,200,50,0,0,0,Example note
```

## 現在の状況と課題

-   PyVistaを使用して断面（輪郭線）を生成しています。
-   LOCATOR中心の半径200mmの範囲のビュー表示については、カメラの平行投影スケールで調整を試みています。
-   「真の断面図」としての品質（例えば、断面の塗りつぶし、より精密な範囲クリッピングなど）については、さらなる改善の余地があります。
-   複雑なOBJファイルや、サポート外のジオメトリを含むOBJファイルでは、メッシュの読み込みやスライス処理に失敗する場合があります。
